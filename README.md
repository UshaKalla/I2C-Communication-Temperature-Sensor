# I2C-Communication-Temperature-Sensor

A Raspberry Pi Pico-based environmental monitor that measures temperature using a TMP102 sensor and displays real-time data through an I²C LCD.

## Features
- Raspberry Pi Pico + MicroPython firmware
- TMP102 temperature sensor integration
- I²C LCD telemetry display
- Custom GPIO button and LED controls
- Register-level I²C communication
- SDA/SCL debugging using Digilent WaveForms logic analyzer

## Hardware
- Raspberry Pi Pico
- TMP102 Temperature Sensor
- I²C LCD Display
- Push Buttons and LEDs

## Implementation
- Developed MicroPython firmware for sensor communication and peripheral control.
- Processed raw 12-bit TMP102 sensor data using bit manipulation.
- Validated I²C communication and hardware reliability using logic analyzer measurements.
